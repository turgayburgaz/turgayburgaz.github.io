youtube-icerik

youtube-icerik is a private, single-user tool used by Turgay Burgaz to manage his own YouTube channels (@turgayburgaz, @SmallWonderings).

It runs only on the owner's computer and uses the YouTube Data API and YouTube Analytics API to:

  • upload and schedule the owner's own videos, and add their subtitles, titles and descriptions in other languages;
  • read view, like and watch-time statistics of the owner's own channels.

It is not offered to other users and does not access anyone else's account.
